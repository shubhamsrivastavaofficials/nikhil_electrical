# Adding Real Business Images

Replace the placeholders referenced in the code with real photos of the shop:

1. `public/images/hero/storefront.jpg` — used in SEO/social share metadata (og:image).
   Recommended size: 1200x630px, JPG or WEBP, under 300KB.
2. Gallery, service and product images should NOT be placed here manually —
   upload them through the Admin Dashboard (`/admin/gallery`, `/admin/services`,
   `/admin/products`) so they go through the upload pipeline and get stored in
   Vercel Blob (production) automatically.

See the main README.md → "Adding Real Business Images" section for full guidance
on photographing the shop, motor binding workstation, and products.
